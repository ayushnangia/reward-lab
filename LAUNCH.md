Reward Lab is an interactive note on reward distributions and transfer. Start with reported cross-domain GRPO results from Yang et al., then inspect how reward weights interact with shared gradient directions. Bring your own checkpoint outputs to compare held-out domains, prompt regressions, and pass@k.

Live: https://ayushnangia.github.io/reward-lab/

Code: https://github.com/ayushnangia/reward-lab

The opening matrix is a transcription of published results, not our experiment. The gradient figure is a constructed first-order explanation. The separate algorithm lab uses finite policies; it is not LLM training.

Use `assets/social-card-v4.png` for the current link preview. The older `reward-lab-demo.mp4` illustrates constructed sampling distributions, not the reported transfer study.
